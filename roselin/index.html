PREGUNTAS FRECUENTES

Antes de empezar,
dejemos todo claro.

¿Qué tipo de páginas web puedo solicitar?+

Landing pages, sitios corporativos, portafolios y tiendas online. El alcance se define a partir de los objetivos, el contenido y las funciones necesarias.

¿Puedo mejorar una web que ya tengo?+

Sí. Podemos revisar la experiencia actual y conversar sobre un rediseño, una mejor organización del contenido o nuevas funcionalidades.

¿También puedo consultar por aplicaciones?+

Sí. El área contempla aplicaciones web y propuestas para apps móviles. Diseño, desarrollo, tecnología y publicación se delimitan para cada proyecto.

¿Qué define el precio de una web?+

Los requisitos, la cantidad y complejidad de las funciones, los contenidos y el alcance. La propuesta debe aclarar entregables, revisiones y condiciones antes de comenzar.

¿Las interfaces mostradas son proyectos realizados?+

Las interfaces identificadas como conceptos son exploraciones visuales. No se presentan como proyectos entregados a clientes.
